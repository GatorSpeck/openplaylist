# Frontend Source

This folder contains all client application source code.

## Top-Level Areas

- `components/`: UI components grouped by feature area
- `contexts/`: React context providers
- `repositories/`: API client/repository layer used by UI code
- `lib/`: shared frontend utilities and hooks
- `styles/`: global and component stylesheet assets
- `tests/`: frontend tests and test helpers

## Entry Points

- `main.jsx`: app bootstrap
- `App.jsx`: primary app shell and route-level composition
