# Common Components

Reusable UI components shared across multiple feature areas.

## Current Components

- `BaseModal.tsx` and `Modal.jsx`: modal foundations
- `ContextMenu.tsx`: reusable menu interactions
- `DarkModeToggle.tsx`: theme mode control
- `TrackDetailsModal.tsx`: shared track metadata display/edit surface
- `SimilarTracksPopup.tsx`: related-track suggestion UI

## Editing Notes

- Keep props generic and reusable.
- Avoid feature-specific API calls in this folder.
