# Frontend Library Utilities

This folder contains shared utility functions, hooks, and mapping helpers.

## Current Modules

- `cookieUtils.ts`: cookie read/write helpers
- `mapToTrackModel.tsx`: API-to-UI model mapping helpers
- `misc.tsx`: shared utility helpers
- `useJobTracker.tsx`: reusable job tracking hook
- `PlaylistEntry.tsx`: shared playlist entry type/model helpers

## Notes

- Keep this folder free of direct rendering concerns.
- Prefer pure and testable helpers where possible.
