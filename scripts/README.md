# Project Scripts

This folder provides top-level helper scripts for common development workflows.

## Scripts

- `setup.sh`: initialize dependencies and local setup
- `dev.sh`: start local development stack
- `test.sh`: run project test suites
- `lint.sh`: run linting/quality checks
- `ytm_test.py`: utility/testing script for YouTube Music integration flows

## Usage

Run from the repository root:

```bash
./scripts/setup.sh
./scripts/dev.sh
./scripts/test.sh
./scripts/lint.sh
```
