**Branch**: `005-tailwind-migration` | **Date**: 2026-03-21 | **Spec**: [spec.md](./spec.md)  
**Input**: Feature specification from `/specs/005-tailwind-migration/spec.md`

## Summary

Migrate the entire React frontend from 17 hand-crafted CSS files to the Tailwind CSS utility-class framework. The migration delivers dark mode (OS detection + user toggle + persistence), full responsiveness from 320 px to 1440 px+, visual consistency via centralised design tokens, and the elimination of all legacy per-component stylesheets — all incrementally without breaking the production build at any intermediate step.

## MUI Coexistence Strategy

The app uses MUI v6 for complex interactive components (modals, icons, drawers). MUI injects its own `<style>` tags at runtime. Tailwind and MUI must coexist without specificity conflicts.

**Chosen approach**: Configure Tailwind with `corePlugins: { preflight: false }` to suppress the global CSS reset (Preflight), which would otherwise break MUI component styling. Tailwind utility classes are applied directly to custom markup; MUI components continue to use their own system unchanged. Where MUI component interiors need dark-mode theming, use MUI's built-in `ThemeProvider` to supplement.

## Dark Mode Architecture

**Strategy**: Tailwind `darkMode: 'class'` — a `dark` class is toggled on the `<html>` element.  
**Preference resolution order**: (1) user explicit choice stored in `localStorage`, (2) OS `prefers-color-scheme` media query.  
**ThemeProvider**: A new `ThemeProvider` React context component owns the preference state, exposes a `useTheme()` hook, and syncs the `dark` class to `<html>` on render.  
**Toggle**: A `DarkModeToggle` button component reads and writes via `useTheme()`.

## Handling Dynamic Styles

`PlaylistGrid` computes `gridTemplateColumns` at runtime from `visibleColumns`. This cannot be expressed as a static utility class. These values are kept as inline `style` props (`style={{ gridTemplateColumns: getGridTemplate() }}`). This is the accepted pattern per FR-012 and records no custom CSS.

## Incremental Safety

Each component group can be migrated independently. The build remains green because:
1. Tailwind's Preflight is disabled — removing CSS imports will not suddenly un-style MUI components.
2. Legacy CSS files are deleted only in US5, after all components are migrated.
3. Each PR/commit migrates one component group and keeps the existing CSS imports alongside the new utility classes until the group is complete.
